Local / Docker: copy .env.example to .env, fill in the Supabase project URL and service_role key (Supabase dashboard → Project Settings → API Keys), then restart.

Vercel / Cloud: add SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY (or SUPABASE_API_KEY + NK_DB_SECRET) under Project Settings → Environment Variables, then redeploy.

The service_role key stays on this server. It is never sent to browsers.
